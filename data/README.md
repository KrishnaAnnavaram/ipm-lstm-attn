# Data

This repository commits no dataset. All data is synthetic and the package makes it on demand.

## Source

| Item | Value |
|---|---|
| Source name | Random "RHS" instances in the style of the DC3 benchmark (Donti, Rolnick and Kolter, "DC3: A learning method for optimization with hard constraints", ICLR 2021) |
| URL | No download. `ipm_lstm_attn.datasets.generate` makes the instances with a seeded `numpy.random.Generator`. |
| License / terms | Generated by this package (MIT). No third-party data. |

## Files

`ipm-lstm-attn generate` (or any command with `--config`) writes two files per dataset into
`IPM_LSTM_ATTN_DATA_DIR` (default `data/generated/`). Git ignores them.

| File | Contents |
|---|---|
| `<family>_n<n>_eq<p>_in<m>_N<count>_s<seed>.npz` | Arrays (float64): `Q` (n, n), `p` (n,), `A` (p, n), `G` (m, n), `c` (m,), `b` (count, p), and `H` (m, n, n) for `qcqp` only |
| `<same name>.json` | Manifest: `family`, `n_var`, `n_eq`, `n_ineq`, `n_instances`, `seed`, `generator_version`, `sha256` |

The loader also accepts the old name `X` for `b` and a trailing axis of size 1. It never rewrites a file.

## Rules

- A dataset file is written once. A second write with different content stops with `ImmutableDataError`.
- The loader checks the keys, the shapes, finite values and the SHA-256 value of the manifest.
- The train, validation and test splits come from one seeded permutation of the instance indices.

## Not included

The nonconvex QP benchmark instances of the upstream project (`qp1`, `st_rv*` and others) are not
supported in this version.
